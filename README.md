# hom pour Homebrew

```
brew install hom-app/tap/hom
```

Installe l'app hom sur le Mac. Ouvre-la une première fois depuis Applications : le hub démarre ensuite avec la session et s'ouvre dans le navigateur, à l'adresse http://localhost:8765.

- Mettre à jour : `brew upgrade hom`
- Désinstaller : `brew uninstall hom` (les données restent) ou `brew uninstall --zap hom` (tout effacer)

Plus d'informations : https://gethom.app
